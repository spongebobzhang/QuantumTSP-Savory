# Exp3: Static QTSP Throughput Regression

`run_static_regression.jl` measures ACK throughput for fixed `(W, w)` pairs on
the SURFnet topology. It does not perform QTSP updates. The output is the
response surface used to compare the simulator with the analytical throughput
regression.

Run from the repository root:

```bash
julia --project=. simulation/qtsp/experiment/exp3/run_static_regression.jl \
  --case theory
python3 simulation/qtsp/experiment/exp3/plot_static_regression.py \
  simulation/qtsp/experiment/exp3/result/<batch_id>
```

Use a one-point, one-replicate smoke run before launching the full grid:

```bash
julia --project=. simulation/qtsp/experiment/exp3/run_static_regression.jl --smoke
```

Available sweeps are:

- `baseline`: `chi=30`, `W={1,2,4,8,16,32}`;
- `theory`: `chi=3`, `W={4,8,16,32,64}`, reducing window saturation;
- `theory_fine`: `chi=3`, `W={4,8,12,16,24,32,48,64}` and Werner spacing
  of 0.05, giving a finer response surface;
- `theory_dense`: `chi=3`, 24 window sizes and 80 Werner values,
  giving 1920 parameter combinations with 5 repeats each (9600 runs);
- `large_window`: `chi=30`, `W={16,32,64,96}`.

Run all four sweeps with `--all`. Each sweep writes a separate timestamped
batch directory.

To build `theory_dense` while reusing runs from an existing `theory_fine`
batch, pass `--reuse`. Matching `(W,w)` replicates are copied and only missing
grid points are simulated:

```bash
julia --project=. simulation/qtsp/experiment/exp3/run_static_regression.jl \
  --case theory_dense \
  --reuse simulation/qtsp/experiment/exp3/result/theory_fine_<timestamp>
```

The default grid has 6 window sizes, 10 Werner values (including the
analytical stationary point `w = 1/3`), and 20 independent replicates (1200
network runs). Edit the constants at the top of the Julia script to change the
grid, route, duration, or physical parameters.

Each batch contains:

- `config.txt`: complete parameter snapshot;
- `static_regression_runs.tsv`: one row per `(W, w, replicate)`;
- `static_regression_grid.tsv`: grouped means, standard deviations, and counts;
- `static_regression_surface3d.png` (or `static_regression_surface3d.html` if
  Matplotlib 3-D is unavailable): the main 3-D response surface
  `(W, w) -> mean ACK throughput`;
- `static_regression_heatmap.png` and `static_regression_slices.png`: 2-D views
  of the same response surface, generated by the Python plotting script.

The current experiment uses SURFnet edge-based classical delays, hop-by-hop
forwarding, and no entanglement swapping. `distance_km` is the source
attenuation-model distance and is not a per-edge SURFnet quantum distance.
